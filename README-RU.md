# Термостат потолочного вентилятора на Arduino Nano с управлением по радиоканалу 433 МГц

## Описание
Arduino-проект для автоматического управления потолочным вентилятором по радиоканалу **433 МГц** на основе показаний двух датчиков температуры **DS18B20**.

Проект предназначен для периодического разгона горячего воздуха, который скапливается под потолком от камина.

Основной скетч — `sketch-cft-433mhz.ino`. Два дополнительных скетча используются для сканирования и подбора радиокодов/параметров передачи.

## Что делает проект

- Считывает температуру с двух датчиков DS18B20.
- Включает вентилятор, если температура на одном из датчиков выше заданного максимума.
- Выключает вентилятор, если температура на одном из датчиков ниже заданного минимума.
- Отправляет RF-команды 433 МГц через библиотеку `RCSwitch`.
- Использует последовательности кодов пульта для команд включения, выключения и переключения направления.
- Показывает состояние системы через зелёный и красный LED.

## Состав скетчей

| Файл | Назначение |
| --- | --- |
| `sketch-cft-433mhz.ino` | Основной скетч автоматического управления вентилятором по температуре. |
| `sketch-radio-input-scan.ino` | Приём и вывод RF-кодов с пульта в Serial Monitor. Используется для захвата кодов с пульта устройства. |
| `sketch-radio-output-scan.ino` | Перебор `pulseLength` и отправка известных кодов. Используется для подбора рабочей длины импульса. |

## Необходимые компоненты

- Arduino-совместимая плата.
- RF-передатчик 433 МГц.
- RF-приёмник 433 МГц для сканирования кодов.
- 2 датчика температуры DS18B20.
- 2 светодиода для индикации состояния.
- Резисторы для светодиодов.
- Подтягивающие резисторы для DS18B20, 4.7 kΩ между DATA и VCC.

## Библиотеки

Установите библиотеки через Arduino IDE Library Manager:

- `RCSwitch`
- `OneWire`
- `DallasTemperature`

## Подключение

Основной скетч использует следующие пины:

| Назначение | Пин Arduino |
| --- | --- |
| RF-передатчик DATA | D2 |
| Зелёный LED | D4 |
| Красный LED | D6 |
| DS18B20 #1 DATA | D8 |
| DS18B20 #2 DATA | D10 |

Скетч для приёма RF-кодов использует приёмник на пине **D2**, через interrupt `0`.

## Настройки температуры

В основном скетче пороги заданы так:

```cpp
const short int MIN_TEMPERATURE = 37;
const short int MAX_TEMPERATURE = 40;
```

Логика работы:

- если вентилятор выключен и температура на одном из датчиков выше `MAX_TEMPERATURE`, вентилятор включается;
- если вентилятор включён и температура на одном из датчиков ниже `MIN_TEMPERATURE`, вентилятор выключается.

## RF-настройки

В основном скетче используются параметры:

```cpp
mySwitch.setProtocol(1);
mySwitch.setPulseLength(270);
```

Рабочий `pulseLength` подбирался отдельным скетчем `sketch-radio-output-scan.ino`.

## Как пользоваться

1. Откройте `sketch-radio-input-scan.ino` и загрузите его в Arduino.
2. Подключите RF-приёмник 433 МГц к D2.
3. Откройте Serial Monitor на скорости `9600`.
4. Нажимайте кнопки на пульте и сохраните полученные RF-коды.
5. При необходимости используйте `sketch-radio-output-scan.ino`, чтобы подобрать корректный `pulseLength`.
6. Обновите массивы кодов в `sketch-cft-433mhz.ino` под ваш пульт.
7. Загрузите основной скетч `sketch-cft-433mhz.ino`.
8. Проверьте работу датчиков температуры и RF-команд.

## Индикация

- Зелёный LED мигает 3 раза при старте, затем остаётся включённым.
- Красный LED включается, когда вентилятор запущен.
- Если первый датчик DS18B20 не найден, красный LED мигает один раз в секунду 10 раз.
- Если второй датчик DS18B20 не найден, красный LED мигает двойными вспышками 10 раз.

## Светодиоды

Для большего энергосбережения системы лучше использовать регулировку яркости по ШИМ.  
Поставить на плату резисторы:

- Красный 3 мм: `680 Ом`
- Зелёный 3 мм: `470 Ом`

И подключить светодиоды к соответствующим пинам на плате контроллера.  
У Arduino Nano ШИМ поддерживают пины `D3`, `D5`, `D6`, `D9`, `D10` и `D11`.

Регулировка яркости выполняется командами:

- `analogWrite(LED_R, 0)` — минимум / выключено
- `analogWrite(LED_R, 255)` — максимальная яркость

Значение может быть в диапазоне от `0` до `255`.

## Примечания

- RF-коды в проекте привязаны к конкретному пульту и устройству. Для другого пульта их нужно заново считать.
- В основном скетче используется циклическая очередь кодов, потому что один и тот же тип команды имеет несколько последовательных значений.
- После старта выполняется короткая калибровка: включение вентилятора, переключение направления и выключение.
- Перед постоянным использованием проверьте работу системы вручную и убедитесь, что команды не конфликтуют с другими 433 МГц устройствами.
- Таблица `Button-codes.xlsx` содержит сохранённые RF-коды кнопок пульта.
